# A320 documents

Custom A320 procedures for the Fenix EFB.

**[Download the latest SOP (PDF)](https://github.com/Hannnes1/a320-docs/releases/download/pdf/sop.pdf)**, printable in black and white. All PDFs are on the [release page](https://github.com/Hannnes1/a320-docs/releases/tag/pdf).

## Files

- `sop.md`: the SOP, in the Fenix EFB Markdown format
- `efb-preview.html`: preview of how the documents look on the EFB in the Fenix
- `efb-pdf.mjs`: builds the printable PDF (`node efb-pdf.mjs sop.md`, see `--help`)
